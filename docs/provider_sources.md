# منابع سرویس‌دهنده‌های خودرو

این نگاشت بر اساس خدمات عمومی قابل مشاهده در سایت‌های ارائه‌دهنده انجام شده است:

- ETAX: خدمات مالیات نقل و انتقال خودرو و دیون مرتبط با مالیات.
- iToll: استعلام/پرداخت خلافی خودرو، عوارض آزادراهی و چند خدمت خودرویی دیگر؛ همچنین صفحه همکاری B2B دارد.
- Bimeh.com: استعلام بیمه شخص ثالث و خدمات بیمه خودرو.

برای اتصال مستقیم production، endpoint/API/B2B مجاز هر سرویس باید در متغیرهای backend قرار بگیرد. این پروژه از scraping HTML استفاده نمی‌کند.
